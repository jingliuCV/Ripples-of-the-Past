# 果修金的记忆档案

> 一个面向入门学习的互动静态网站练手项目，用来练习页面设计、网页动画、原生 JavaScript 交互和静态站点部署。

**项目状态：** 学习项目，持续完善中  
**在线预览：** 部署后在这里补充公开访问地址

## 项目简介

这是一个以「记忆之书」为主题的互动个人主页。访问者从书封进入目录，可以浏览角色档案、学习进度、支线任务、神谕牌和火种试炼，也可以打开本地短笺写下内容。

项目使用 HTML、CSS 和原生 JavaScript 完成，没有前端框架，也没有后端服务。所有视觉和交互效果都放在静态文件中，适合用来学习一个完整网页从制作到部署的过程。

## 功能展示

- 书本封面开场动画与翻页转场
- 六个可切换的内容模块
- 14 张不重复抽取的神谕牌
- 12 枚火种点亮进度与完成反馈
- 三首背景音乐切换、播放和音量调节
- 可在浏览器本地编辑并复制的短笺
- 桌面端和移动端响应式布局
- 键盘操作、焦点样式与减少动态效果适配
- 静态站点安全响应头配置

> 短笺只保存在当前浏览器中，不会上传到服务器。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| HTML5 | 页面结构和语义化内容 |
| CSS3 | 响应式布局、渐变、3D 翻页与关键帧动画 |
| JavaScript | 页面切换、抽牌、点灯、音乐和剪贴板交互 |
| WebP / JPG / PNG | 页面视觉素材 |
| M4A / AAC | 背景音乐 |
| `_headers` | Cloudflare Pages 或 Netlify 的缓存与安全响应头 |

## 本地运行

可以直接双击 `index.html` 预览页面。为了避免浏览器对本地音频和剪贴板功能施加额外限制，更推荐启动一个本地静态服务器。

需要先安装 Python，然后在项目目录中执行：

```bash
python -m http.server 8000
```

浏览器访问：

```text
http://localhost:8000
```

也可以使用 VS Code 的 Live Server 扩展打开项目。

## 部署

### 方案一：Cloudflare Pages

1. 将项目上传到 GitHub 公开仓库。
2. 登录 Cloudflare Pages，选择 **Connect to Git**。
3. 选择对应仓库。
4. 构建命令留空。
5. 如果仓库根目录就是本站文件，构建输出目录填写 `/`。
6. 完成部署，并把生成的访问地址补充到本 README 顶部。

Cloudflare Pages 会读取根目录中的 `_headers`，为页面应用缓存和安全响应头。

### 方案二：Netlify

1. 登录 Netlify，导入 GitHub 仓库。
2. 不需要设置构建命令。
3. 将发布目录设置为仓库根目录或站点实际所在目录。
4. 完成部署并补充公开访问地址。

Netlify 同样支持 `_headers` 文件。

### 方案三：GitHub Pages

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 `main` 分支和站点所在目录。
4. 保存并等待 GitHub 生成访问地址。

GitHub Pages 可以正常展示静态页面，但会忽略 `_headers`，所以安全响应头配置不会生效。

## 隐私与公开发布检查

公开仓库前，请逐项确认：

- 页面中的姓名、团队、职务、面试进度等个人信息是否愿意长期公开；不希望公开时，改用化名或泛化描述。
- 截图画面中是否带有游戏 UID、账号昵称、聊天记录或其他可识别信息；公开前进行裁剪、打码或替换。
- 原始图片是否带有设备型号、拍摄时间、定位等 EXIF 元数据；发布前清理元数据并重新导出图片。
- Git 提交邮箱是否使用了希望公开的地址；可以在 GitHub 设置中启用隐私邮箱。
- 仓库中不能出现密码、访问令牌、API Key、`.env` 文件或私钥。
- 使用第三方角色图片、游戏截图、音乐和字体前，确认授权范围，并在仓库中说明素材来源。

页面当前没有后端请求、第三方统计脚本、Cookie 或账号系统，短笺内容不会发送到网络。以后增加留言、登录或数据统计功能时，需要重新评估隐私说明和安全措施。
